# 💬 Real-Time Chat App

A simple real-time chat application built with **Node.js**, **Express**, and **Socket.io**. Users can join chat rooms and exchange messages instantly with others.

## 🔧 Tech Stack
- Node.js + Express
- Socket.io
- HTML, CSS, JavaScript

## 🚀 Features
- Real-time messaging
- Multi-user chat rooms
- Join/leave notifications

## 📦 Setup

```bash
git clone https://github.com/your-username/realtime-chat.git
cd realtime-chat
npm install
node server.js
